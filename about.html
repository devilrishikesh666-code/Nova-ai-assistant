About Nova

What Nova is

Nova is a 3D AI assistant for chat, image creation, and coding help. It's built with plain HTML, CSS, and JavaScript, so it runs on any static host such as GitHub Pages.

How access works

The AI API key is stored only on a private server-side proxy. Chat requires the owner token, and visitors can't see or use the key. Image creation uses a free service that needs no key.
